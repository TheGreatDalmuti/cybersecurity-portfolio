Challenge : Nice netcat…

Category : General Skills

Time : 5 minutes

Objective : Using netcat to connect to a remote service (DNS), using the given output and identifying it as ASCII-encoded, and decode that output into english text to recover the flag.

Concepts Learned : Usage of networking utility, transferring data, decoding encoded data.

Key Takeaways : Penetration testers should always be familiar with the different types of encoding utilized and choose an appropriate tool to decode them.
