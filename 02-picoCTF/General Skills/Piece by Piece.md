Challenge : Piece by Piece

Category : General Skills

Time: ~20 minutes

Objective: SSH into a remote computer across another network, analyze file contents using commands, and combine files into a singular zip, finally unzipping the combined file in order to find the flag.

Concepts Learned: File inspection, data reconstruction, Linux command-line operations, and text processing.

What I Learned : I learned how to perform a remote SSH in order to gain access to a target and I also became aware of how zip files work using the command line interface in order to find the flag. 

Key Takeaways : SSH is a powerful tool that allows you a secure way to remotely access and manage Linux systems over an encrypted connection
SSH relies on authentication to securely establish remote connections. 

Zip is a command that allows you to compress one or more files into a .zip file
