Challenge : Ping-cmd

Category : General Skills

Time : 15 minutes

Objective: The objective of the ping-ctf challenge is to exploit a command injection vulnerability in a program that claims to only ping one ip address. 

Command Used: cat

Concepts Learned : Command injection, Input Validation, and Linux Command Line

Key Takeaways : Command injection is a powerful tool that when used correctly can be one of the most critical web vulnerabilities 
Developers should ensure that they avoid the use of the power shell when taking user input. If this is not possible, strict input validation should be implemented as a proper response.
