Challenge: Log Hunt
Category: General Skills
Time: ~40 minutes
Objective: Download the provided server log, analyze its content using commands, and swift through to identify scattered fragments of flag, and combine fragments together to complete the flag. 
Concepts Learned: File downloading, String Filtering, File inspection, Data Reconstruction.
Commands Used: grep, wget, cat
What I learned :  I learned how to use “wget” to download files for inspection and I also became aware of how “grep” is utilized in cybersecurity in order to search for specific text in files. I also practiced researching unfamiliar Linux commands when I tackled  a hurdle. 
Key Takeaways : 
Grep is one of the most useful Linux commands and is utilized by cybersecurity professionals in order to filter large amounts of text efficiently. 
Looking up documentation and unknown concepts is an important cybersecurity skill.
